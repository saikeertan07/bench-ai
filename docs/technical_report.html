1. Executive Summary & Core Value Proposition

Context & Operational Problem: During high-severity software outages, Site Reliability Engineers (SREs) and incident responders encounter multi-modal diagnostic payloads—including multiline Java/Python/Node.js stack traces, structured JSON logs, JWT authorization tokens, and raw cURL network dumps. Standard investigative workflows force engineers to paste sensitive tokens and proprietary system logs into unvetted public online utilities, creating catastrophic security and regulatory compliance risks under GDPR, HIPAA, and DPDP.

Architectural Solution: BENCH AI provides an air-gapped, zero-backend industrial test instrument that unifies the entire triage and root-cause analysis cycle into a single client-side workstation. Modeled after hardware oscilloscopes and logic analyzers, it operates entirely within the browser DOM using pure client-side heuristics, modular channel abstractions, and zero-trust memory hygiene.

Core Architectural Paradigms Deployed
1. Zero-Network Air-Gap: 100% of payload parsing, regex extraction, token decoding, and heuristic inference executes client-side. Zero bytes leave the engineer's browser.
2. 8-Channel Bus Topography: Modular rack channels (CH01–CH08) decoupled via a centralized reactive store (js/state.js).
3. Pluggable AIProvider Interface: Contract-based separation of inference abstractions (js/ai-engine.js) allowing deterministic local heuristics and future LLM backends.
4. Automated Maintenance & Telemetry: Continuous operational streak verification via GitHub Actions and deterministic PRNG week-scheduling.

2. System Architecture & Data Topology

BENCH AI is implemented as a high-density, zero-build client-side application. The runtime operates without Node.js server dependencies or server-side rendering (SSR), completely eliminating server-side attack vectors (e.g., SSRF, remote code execution, SQL injection).

2.2 8-Channel Industrial Rack Breakdown

CH01 • Ingest & Normalization
Capture Channel (js/channels/capture.js)
Dropzone, clipboard paste listener, and instant format sniffer feeding raw bytes into BAI.detector.
CH02 • Triage & Signals
Diagnose Channel (js/channels/diagnose.js)
Synthesizes severity ratings (CRITICAL, HIGH, MEDIUM, LOW), confidence %, and error tokens.
CH03 • Dependency Graph
Root Cause Channel (js/channels/rootcause.js)
Chronological causal chain mapping upstream trigger faults, state corruption, and blast radius.
CH04 • Remediation
Fix Channel (js/channels/fix.js)
Unified diff generation, config remediation blocks, and copy-pasteable terminal rollback commands.
CH05 • QA & Invariants
Verify Channel (js/channels/verify.js)
Regression verification checklist, invariant validation rules, and post-patch health verification.
CH06 • Protocol Debugger
API Inspector Channel (js/channels/api.js)
HTTP request/response dissection, cURL parsing, authorization headers, and latency profiling.
CH07 • Telemetry Engine
Log Stream Channel (js/channels/logs.js)
High-speed log viewer with regex filtering, loglevel grouping, and timestamp chronological alignment.
CH08 • Audit & Replay
History Channel (js/channels/history.js)
Local session storage playback, status filtering (OPEN vs RESOLVED), and JSON export.

3. Database Schema & Persistence Layer

In accordance with BENCH AI's zero-trust security paradigm, data persistence is decoupled from remote central databases. This guarantees zero compliance exposure under GDPR, HIPAA, and DPDP, as confidential production tokens never leave engineer workstations.

3.1 Storage Tier Architecture & Lifecycle

Storage Category Engine / Structural Mechanism Capacity & Eviction Strategy Cryptographic Boundary
Primary Persistence Browser localStorage (Key: bench_ai_history_v1) FIFO Circular Buffer (Max 100 sessions via sessions.slice(0, 100)) Browser Origin Isolation (Same-Origin Policy)
Transient Session Cache In-Memory Heap Object (window.BAI.state) Ephemeral: Reclaimed on browser tab refresh / close Process Memory Boundary
Relational Database PostgreSQL 16 / SQLite (Server-side) Not Implemented (Intentionally Omitted) N/A
Unstructured Object Store AWS S3 / Google Cloud Storage Not Implemented (Intentionally Omitted) N/A

5. Zero-Trust Security & Compliance Posture

5.1 Threat Matrix & Mitigations

Threat Vector Standard Attack Scenario Concrete Implemented Defense Mechanism Verification Status
Cross-Site Scripting (XSS) Malicious JavaScript injected via pasted log traces or JWT claims. All dynamic strings pass through BAI.escapeHtml() replacing &, <, >, ", ' before DOM insertion. Implemented & Verified
Data Exfiltration Credentials or tokens leaked to unauthorized third-party analytics. Air-gapped architecture. Zero outbound fetch() or XMLHttpRequest calls in codebase. Zero analytics SDKs. Implemented & Verified
Storage Quota Exhaustion Attacker pastes huge log files to crash browser localStorage. Enforces strict 100-session cap via sessions.slice(0, 100) with try/catch quota guardrails. Implemented & Verified
Remote Code Execution Malicious input executed via dynamic JavaScript eval(). Strict avoidance of eval() and new Function() across all 18 JavaScript modules. Implemented & Verified
